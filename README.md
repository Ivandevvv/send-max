## Требования

- **Node.js** 20.19+ или 22.12+ (проверить: `node -v`)
- **npm** 10+ (проверить: `npm -v`)

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Ivandevvv/send-max.git

# 2. Установить зависимости
npm install
```

## Запуск

```bash
npm run dev
```

Проект будет доступен по адресу: **http://localhost:5173**
